# bungakuquote

小説・随筆・古典・詩歌から、日替わりで名文を1つずつ「展示」するツール。

## 機能
- トップページで「本日の展示」として、その日の1件を表示（日本時間の日付で決まります）
- 展示ページ（`/quote/<番号>`）・展示一覧（`/all`、ジャンル別）・ランダム表示（`/random`）
- 各展示に「引用文をコピー」ボタン（本文＋著者＋作品名のプレーンテキスト）
- JSON API：`/api/today`、`/api/random`、`/api/quote/<番号>`

## データについて
- 収録は30件。すべて著作権保護期間を満了したパブリックドメインの作品から採っています。
- 引用文は青空文庫等の原文と照合して収録しています（表記は読みやすい現代表記に寄せたものがあります）。

## 動かし方
```bash
pip install -r requirements.txt
python app.py
```

## テスト
```bash
pip install pytest
pytest tests/
```
